# Contextual Understanding of Slang and Hashtags in Social Media for Improved Anonymization

## Описание
Hепозиторий содержит код, данные и результаты исследования по извлечению смысла сленговых выражений в коротких постах социальных сетей с использованием энкодеров без дообучения.  
Цель проекта — повысить качество автоматической анонимизации и понимания сообщений за счет контекстного анализа сленга.

## Основные компоненты

1. **Сбор и подготовка данных**
   - Сбор постов из социальных сетей
   - Анонимизация исходных текстов
   - Создание датасета с маскированными токенами

2. **Получение контекстных представлений**
   - Masked-token embeddings с BERT-base
   - (Опционально) Sentence-level embeddings с SBERT

3. **Кластеризация и анализ**
   - KMeans для выявления значений сленговых слов
   - Автоматический выбор числа кластеров (Silhouette score)
   - Декодирование центроидов в синонимы и пояснения

4. **Визуализация**
   - PCA и t-SNE для снижения размерности эмбеддингов
   - Scatterplots с окраской по кластерам
   - Примеры контекстов для каждого кластера

5. **Эксперименты**
   - Анализ зависимости качества интерпретации от числа контекстов N
   - Сравнение маскированных и sentence-level эмбеддингов
   - Генерация таблиц и графиков для публикации
